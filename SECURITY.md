# Security Policy

## Reporting a vulnerability

Please **do not open a public issue** for security problems. Use GitHub's private vulnerability reporting: **Security → Report a vulnerability** on this repository.

Include affected component, reproduction steps and impact. We aim to acknowledge reports within 5 business days.

## Scope

The project is in early development (M0). There is no production deployment yet. Once a demo environment exists, its scope will be listed here.

## Our own practices

- Threat model: [docs/security/threat-model.md](docs/security/threat-model.md)
- No secrets, credentials or personal data are committed to this repository; secret scanning and push protection are enabled.
